# Laundry Service Website

This is a simple laundry service website made using HTML and CSS as part of an assignment.

## Features

- Navigation bar with Home, Services, About Us and Contact Us.
- Logo on the left and user name on the right.
- Hero section with a heading, description and booking button.
- Laundry-related image on the right side.
- Used `display: inline-block` to arrange the elements without using flexbox.
- Used viewport units to fit the hero section on the screen.

## Technologies Used

- HTML
- CSS
